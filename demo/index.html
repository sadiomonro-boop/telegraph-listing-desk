How to run it

git clone https://github.com/sadiomonro-boop/telegraph-listing-desk.git
cd telegraph-listing-desk
npm install
export TELEGRAPH_PRIVATE_KEY=0x...   # throwaway wallet, Sepolia testnet only
node src/cli.js --input examples/usdc.json --out out/usdc

Expected: REVIEW — risk 50/100 — 0.05 test USDC — 5 intents — memo: out/usdc/memo.md

Caps: $0.50 per ask, $5 per day. One memo costs 0.05 test USDC. Failed asks are never billed. An invalid application, or an intent that cannot be bought after all fallbacks, produces an INCONCLUSIVE memo and exit code 1 — never a fake success. Sniper mode (pre-trade BUY / NO-BUY) is included but currently unproven: no live miner returns a usable wash-trading verdict for an address-only query — see the README.
